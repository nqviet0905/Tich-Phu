\# Tích Phú – Personal Finance Management App



\## Giới thiệu



\*\*Tích Phú\*\* là ứng dụng Android hỗ trợ quản lý thu chi và lập kế hoạch tài chính cá nhân. Dự án được xây dựng nhằm giúp người dùng theo dõi các giao dịch tài chính và quản lý ngân sách thuận tiện hơn.



\## Mục tiêu dự án



\- Xây dựng ứng dụng quản lý tài chính cá nhân trên nền tảng Android.

\- Hỗ trợ theo dõi thu nhập và chi tiêu.

\- Tìm hiểu và thực hành xây dựng ứng dụng Android kết nối với backend API.

\- Thực hành quản lý mã nguồn bằng Git và GitHub.



\## Công nghệ sử dụng



\- \*\*Android:\*\* Kotlin, Jetpack Compose

\- \*\*Backend:\*\* PHP REST API

\- \*\*Cơ sở dữ liệu:\*\* MySQL

\- \*\*Công cụ phát triển:\*\* Android Studio, XAMPP, Git, GitHub



\## Cấu trúc dự án



```text

Tich-Phu/
```

\## Cài đặt và chạy dự án



\### 1. Android



1\. Cài đặt Android Studio.

2\. Clone repository về máy.

3\. Mở thư mục `android-app` bằng Android Studio.

4\. Cấu hình Firebase theo cấu hình riêng của dự án nếu được yêu cầu.

5\. Đồng bộ Gradle và chạy ứng dụng trên emulator hoặc thiết bị Android.



\### 2. Backend API



1\. Cài đặt PHP, MySQL và Composer.

2\. Cấu hình thông tin kết nối cơ sở dữ liệu.

3\. Cài đặt các thư viện PHP theo `composer.json`.

4\. Cấu hình Firebase và email bằng biến môi trường nếu các chức năng này được sử dụng.

5\. Chạy backend trên môi trường PHP phù hợp.



> Lưu ý: Cần cấu hình môi trường và các thông tin bí mật riêng trước khi chạy. Không đưa mật khẩu, khóa riêng Firebase hoặc thông tin xác thực vào GitHub.
